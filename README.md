# AgentX documentation

The documentation website for AgentX.

AgentX is a terminal based AI agent for building and modifying real software projects. This site covers the installation flow, providers, local models, agent architecture, commands, stacks, services, and security.

## Development

```bash
npm ci
npm run start
```

Build the production site with `npm run build`.

## Deployment

The GitHub Pages workflow is intentionally preserved. The custom domain is:

https://agentx.js.org

The `static/CNAME` file is the domain boundary and should not be removed.
