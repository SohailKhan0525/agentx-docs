# Privacy

This documentation site is intended to publish product documentation. Do not submit secrets, API keys, credentials, or private project data through public issue trackers.

AgentX itself may interact with model providers when you use the CLI. The information sent to a provider depends on the provider, model, configuration, and request you make.

For provider specific retention and privacy terms, consult the provider you selected.

## Documentation analytics

This site does not require an account to read the documentation. Any platform level logs or analytics provided by the hosting environment are governed by the platform's own policies.
