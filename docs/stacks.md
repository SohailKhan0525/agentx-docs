# Supported Stacks

AgentX picks the best stack automatically based on your project requirements.

## Next.js 14 (App Router)

Best for: SaaS, marketing sites, blogs, e-commerce
Features: SSR, SSG, API Routes, TypeScript, Tailwind CSS

## React + Vite

Best for: Single page apps, dashboards, tools
Features: Fast HMR, TypeScript, flexible architecture

## Astro

Best for: Content sites, documentation, blogs
Features: Zero JS by default, island architecture, excellent SEO

## Nuxt 3

Best for: Vue-based projects, SSR applications
Features: Vue 3, TypeScript, auto-imports, SSR/SSG

All stacks use TypeScript by default.
