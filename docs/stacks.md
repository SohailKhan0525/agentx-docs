# Supported stacks

AgentX is intended to work with modern web projects while respecting the stack already there.

## Next.js

Read the App Router, TypeScript setup, server boundaries, data layer, and styling before introducing new patterns.

## React and Vite

Useful for client heavy applications, dashboards, and single page tools. Keep existing component and state conventions intact.

## Astro

A good fit for content heavy sites where the client bundle should stay small.

## Nuxt

A Vue oriented option for SSR applications and full stack Vue projects.

## Styling

Follow the repository's current design tokens, primitives, responsive rules, and naming conventions.

A useful prompt:

```text
Inspect the framework and styling setup first.
Do not add a UI library unless the project already uses it
or the implementation plan explains the need.
```
