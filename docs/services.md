# Integrated services

AgentX can help configure services when the project and provider credentials support them.

| Category | Examples |
| --- | --- |
| Authentication | Clerk, Supabase Auth, Firebase Auth, Auth.js |
| Databases | Supabase, Firebase, MongoDB Atlas, Appwrite, PostgreSQL |
| Data | Prisma, Drizzle |
| Payments | Stripe, Lemon Squeezy |
| Email | Resend, SendGrid, Postmark |
| Storage | Cloudflare R2, AWS S3, Supabase Storage |
| Deployment | Vercel, Netlify, Cloudflare Pages, Railway, GitHub Pages |
| Observability | Sentry, PostHog |

## Integration loop

1. Ask AgentX to inspect the application.
2. Name the provider and behavior you need.
3. Review the implementation plan.
4. Put credentials in environment variables or a secret store.
5. Run the project's checks before deployment.

Provider accounts, permissions, billing, and production settings remain under your control.
