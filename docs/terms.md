# Terms

The AgentX documentation is provided to help you understand and use the project.

Examples and commands are provided for development workflows. Review them for your environment before running them, especially commands that modify or delete files.

AgentX, its documentation, and related tooling may change over time. Verify provider APIs, package versions, operating system requirements, and deployment settings against current project sources before production use.

The documentation is not a substitute for reviewing your own code, credentials, infrastructure, or release process.
