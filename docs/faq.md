# FAQ

## Is AgentX for existing projects?

Yes. Reading an existing repository before editing is a central workflow.

## Does my code leave my machine?

It depends on the provider. Hosted providers receive the information required for model requests. Local runners can keep inference on your machine or local network.

## Can I use local models?

Yes. See [Local models](./local-models) for Ollama and LM Studio.

## Where should API keys live?

Use environment variables or a secure credential store. Never commit keys.

## Which operating systems are covered?

The docs cover Windows, macOS, and Linux terminal workflows.

## Is the CLI free?

The AgentX CLI is open source. Model providers may charge for usage, while local inference has hardware and electricity costs.

## Where do I report bugs?

Use the [AgentX CLI repository](https://github.com/SohailKhan0525/agentx-cli) for bugs and feature requests.
