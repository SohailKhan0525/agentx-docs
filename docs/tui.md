---\ntitle: Terminal UI\ndescription: Learn the AgentX Code terminal user interface and built-in agents.\n---\n\n# AgentX Code TUI\n\nAgentX Code is designed around a terminal user interface (TUI) that keeps the active session and development context visible while the agent works.\n\n## Agents\n\nAgentX Code ships with two built-in agents:\n\n- **build** — the default full-access agent for development work.\n- **plan** — a read-only agent for analysis and code exploration. File edits are denied by default, and shell commands require permission.\n\nPress **Tab** to switch between them.\n\nA **general** subagent is also available for complex searches and multistep tasks. Use \`@general\` in a message to invoke it.\n\n## What the TUI is for\n\nThe interface is organized around a live coding session: repository context, the current conversation, tool activity, todos, files, and changes stay close to the work instead of being split across unrelated surfaces.\n\n## Start a session\n\n\`\`\`bash\ncd your-project\nagentx\n\`\`\`\n\nStart with an outcome and constraints. For unfamiliar repositories, switch to **plan** first, inspect the proposed work, then move to **build** when you are ready to make changes.\n
