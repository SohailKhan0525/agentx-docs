# Commands and shortcuts

AgentX provides slash commands for session control and keyboard shortcuts for terminal interaction.

## Slash commands

| Command | Purpose |
| --- | --- |
| `/help` | Show available commands |
| `/clear` | Clear current session context |
| `/model` | Change the active model |
| `/provider` | Change the active provider |
| `/cost` | Show token usage and estimated cost |
| `/theme` | Change the terminal theme |
| `/skills` | List available skills and tools |
| `/exit` | End the session |

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| **Ctrl + C** | Interrupt generation or tool execution |
| **Ctrl + D** | Exit the CLI |
| **Tab** | Autocomplete commands and paths |
| **Shift + Enter** | Add a newline to a multi line prompt |
| **↑ / ↓** | Cycle through prompt history |

Command availability can change as AgentX evolves. Run `/help` inside your installed version for the current list.
