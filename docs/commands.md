# Commands and shortcuts

Run `/help` inside AgentX for the command set available in your installed version.

| Command | Purpose |
| --- | --- |
| `/help` | Show available commands |
| `/clear` | Clear current session context |
| `/model` | Change the active model |
| `/provider` | Change the active provider |
| `/cost` | Show usage and estimated cost |
| `/theme` | Change terminal theme |
| `/skills` | List available skills and tools |
| `/exit` | End the session |

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| **Ctrl + C** | Interrupt generation or tool execution |
| **Ctrl + D** | Exit the CLI |
| **Tab** | Autocomplete |
| **Shift + Enter** | Add a newline |
| **↑ / ↓** | Prompt history |

Command availability can change as AgentX evolves.
