# AgentX

AgentX is a terminal AI agent that builds complete, production-ready websites from scratch.

Describe your website in plain English. AgentX plans it, builds it, deploys it.

## Quick Start

```bash
npm install -g @agent-qofeno/agentx-cli
agentx
```

## How It Works

AgentX works like Claude Code, but specialized for building websites:

1. **Plans before acting** — writes an explicit plan and gets your confirmation
2. **Reads code before editing** — never edits files it hasn't read
3. **Uses tools for everything** — actually runs commands and writes files
4. **Iterates until done** — fixes its own errors until the build passes
5. **Deploys live** — pushes to GitHub and deploys automatically
